# HSTempo

This is a fork of HSTempo (Tempo Measuring Application) found at [https://github.com/hsaito/hstempo_android](https://github.com/hsaito/hstempo_android) updated to work with recent android versions, as the original does not install on Android 15.

HSTempo Neo is a music tempo measurement app. It features a single-tap button that can be tapped in time with the music. The BPM is calculated in real time and displayed on the screen.
